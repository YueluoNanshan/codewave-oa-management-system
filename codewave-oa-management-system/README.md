# OA 办公自动化系统｜网易 CodeWave 低代码项目

> **项目性质：** 基于网易 CodeWave（原轻舟低代码）平台配置开发并导出的 OA 业务源码**展示版**，用于学习成果与求职项目展示。**并非可独立部署的完整工程**。部分 Java/Vue 代码为平台生成代码，不代表逐行手写。

## 项目介绍

面向日常办公业务，涵盖组织与权限管理、考勤、日程、资产管理、企业制度与审批流程等 OA 场景。源码导出中包含 PC 端页面、部分移动端页面，以及 Java 业务服务与实体定义。

## 源码中可辨认的模块

| 模块 | 源码体现 |
| --- | --- |
| 组织权限 | 部门、用户、角色和权限管理 PC 页面及相关服务/实体 |
| 考勤 | 打卡设置、我的打卡、考勤记录相关服务 |
| 日程 | 新建日程、我的日程及日程服务 |
| 资产 | 资产列表、资产申请、我的资产、资产详情、供应商 |
| 企业制度 | 制度列表、制度详情、发布制度相关页面和服务 |
| 审批 | 新建流程、我的流程、请假审批相关页面，以及导出生成的流程服务类 |
| 移动端 | 首页、打卡、我的资产、资产详情等页面 |

以上基于**源代码文件结构**核对，不代表在当前环境已重新运行或完成上线验证。

## 为什么没有完整运行环境？

这是**公开展示用的精选源码**：刻意移除了 `application-*.yml`、数据库/云服务连接配置、平台依赖包、构建缓存、用户上传资源等。CodeWave 平台组件和运行环境依赖未包含，因此直接执行 `mvn` 或 `npm` 不保证可运行。请勿误将此仓库理解为完整可部署的开源替代品。
